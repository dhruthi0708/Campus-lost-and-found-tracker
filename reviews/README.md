## Project Overview

CampusFind is a centralized web-based platform for managing lost and found items within a campus.

The system allows users to:

- Report lost and found items
- Search and filter items
- Find potential item matches
- Submit and verify claims
- Receive notifications
- Communicate through claim-based chat
- Complete secure handover using QR verification
