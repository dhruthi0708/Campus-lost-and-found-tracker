# CampusFind – Project Code

## Intelligent Lost and Found Management System for Campus

CampusFind is a web-based platform designed to help students, faculty, and staff report, search, match, claim, verify, and recover lost and found items within a campus environment.

## Technologies Used

### Frontend
- React.js
- Vite
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MySQL

### Development Tools
- Visual Studio Code
- Git
- GitHub
